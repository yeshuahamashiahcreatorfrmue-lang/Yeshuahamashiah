# 이벤트 "각 7개씩" 제작 경험 기반 보강

8종 이벤트를 7개씩(56개) 만들며 느낀 한계를 리스트로 정리해 전부 구현했다.

## 보강 리스트 (전부 완료)

- [x] **이벤트 이름표(라벨)** — `Event.label`
  - 문제: 같은 종류 이벤트가 많아 `#5 메시지 @22,20`만으로 구분이 어려웠다.
  - 구현: 이벤트마다 메모/이름을 달고, 이벤트 목록에 `#id 이름`으로 표시.
- [x] **다지선다 대화(최대 4개)** — `choiceA~D` + `choiceVar`
  - 문제: 선택지가 A/B 2개뿐이라 분기가 빈약했다.
  - 구현: 선택지 A~D 입력(2개 이상이면 선택지 표시). 선택한 번호(0~3)를 변수에
    저장(`choiceVar`)해 조건 분기에 활용. 2지선다 스위치도 유지.
- [x] **혼합 적 전투** — `Event.battleEnemies[]`
  - 문제: 전투 이벤트가 적 1종×N마리만 가능했다.
  - 구현: 적 목록을 직접 구성(여러 종류). 필드 소환·즉시 턴제 둘 다 적용,
    비우면 기존 단일 적×수량으로 폴백.
- [x] **퀘스트 "NPC와 대화" 목표** — `questObjective==4`
  - 문제: 처치/수집/도달만 있어 전달·심부름·대화 퀘스트를 못 만들었다.
  - 구현: 대상 NPC 이벤트ID 지정. 그 NPC에게 말 걸면 완료(`addTalkProgress`).
    목표/일지/마커에 반영.

## 검증

- 셀프테스트: 이름표·4지선다/선택변수·혼합 전투 목록·NPC 대화 진행 직렬화/로직
  통과(기존 전부 통과 유지).
- 헤드리스 스크린샷: 4지선다 대화(4버튼), 이벤트 인스펙터 상단 "이벤트 이름표(메모)".
