# 이벤트 제작 경험 기반 — 부족분 보강 리스트

이벤트 8종을 만들고 56개를 배치하며 느낀 부족함을 리스트로 정리해 전부 구현했다.

## 보강 리스트 (전부 완료)

- [x] **대사 자동 줄바꿈 + 자동 페이지 분할**
  - 문제: 긴 대사가 한 줄로 그려져 상자 밖으로 넘쳤다.
  - 구현: `wrapToWidth`(공백 우선, 없으면 글자 단위 — 한글 대응)로 상자 폭에 맞춰
    줄바꿈하고 3줄 단위로 페이지 자동 분할. 대사창은 줄 단위 렌더.
- [x] **이벤트 복제 버튼 (옆 칸)**
  - 문제: 비슷한 이벤트를 여러 개 만들 때 매번 처음부터 설정해야 했다.
  - 구현: 인스펙터에 "이벤트 복제 (옆 칸)" — 현재 이벤트를 빈 옆 타일에 복사하고
    선택을 새 이벤트로 이동.
- [x] **스위치 / 변수 디버그 인스펙터 (F3)**
  - 문제: 이벤트 조건/퀘스트 플래그/선택지 결과를 눈으로 확인할 방법이 없었다.
  - 구현: 플레이 중 F3로 켜지는 오버레이가 켜진 스위치 + 모든 변수 값을 표시.
- [x] **오디오 음량 설정 (마스터 / 배경음 / 효과음)**
  - 문제: 음량 조절 수단이 전혀 없었다.
  - 구현: `Audio`에 마스터/음악/효과음 볼륨 + 적용 로직. ESC 메뉴에 "설정" 페이지
    (좌/우로 10%씩 조절, 막대 표시).
- [x] **다중 세이브 슬롯(3) + 불러오기**
  - 문제: 세이브가 slot1 하나뿐이었다.
  - 구현: ESC "저장" → 슬롯 3개 중 선택 저장(사용/빈 표시). 타이틀 "이어하기"는
    가장 최근에 저장된 슬롯을 자동 로드.

## 검증

- 셀프테스트 전체 통과(기존 + 이벤트/퀘스트 직렬화).
- 헤드리스 스크린샷: 긴 대사 줄바꿈, 설정(음량 막대), 저장 슬롯, F3 인스펙터
  (#10/#40 ON, #1=5/#2=12), 이벤트 복제 버튼 확인.
