# 숨은 기능 점검 (4차) — 상점/식품버프편집/이동대상이름

엔진 전 기능을 다시 일일이 체크리스트화하고(감사 + 전 탭/플레이 화면 직접 캡처
확인), **코드/데이터에는 있으나 화면에서 만들/볼 수 없던 부분**만 추려 화면에서
동작하게 했다.

## 전체 기능 체크리스트(요약)와 화면 표시 여부

- [x] 월드/전맵뷰어/맵/NPC/이벤트/캐릭터/에셋/DB 8개 탭 — 모두 화면 표시 확인
- [x] 맵 도구(펜/지우개/채우기/사각형/스탬프/충돌/오브젝트), 줌바, 스크롤바
- [x] 캐릭터 빌더: 모션(방향별 프레임/fps/루프), 칸수, FieldSkill 전 필드 편집
- [x] 이벤트: 8종(메시지/이동/지급/스위치/전투/상점/퀘스트/엔딩), 트리거 3종, 조건스위치
- [x] DB: 아이템/장비/스킬/액터/적 — 액터 전투스킬·스프라이트, 적 스프라이트 포함
- [x] 플레이 HUD: 스탯/목표/포만수분/버프배지/스킬패널/인벤·장비 버튼/미니맵
- [x] 인벤토리(I)·신체부위 장비(C)·ESC 메뉴(아이템/장비/상태)
- [x] 턴제 전투(랜덤 인카운터, 적 스프라이트), 타이틀 새게임/이어하기/MMO 호스트·접속

## 점검 결과: 실제로 화면에 없던 항목 (이번에 수정)

- [x] **상점(`EventType::Shop`)에 구매 화면이 없음**
  - 증상: 상점 이벤트와 접촉하면 화면 없이 즉시 1개 자동 구매만 됐다
    (`GamePlayEvents.cpp` 구 Shop 처리). 상점이라는 기능은 있는데 화면이 없음.
  - 수정: `Phase::Shop` + `openShop/updateShop/drawShop` 추가. 상점 제목·골드·
    상품(아이콘/이름/가격/보유수/설명)·구입/닫기 버튼이 있는 실제 상점 화면.
- [x] **식품 버프 지속(`Item.buffSecs`)을 에디터에서 설정 불가**
  - 증상: 런타임 시간제 버프(2차에서 구현)는 동작하지만, DB 아이템 편집기엔
    `buffSecs` 스테퍼가 없어 항상 0(즉시효과)이었다. 라벨도 "영구 버프"로 오기.
  - 수정: 식품 편집기에 "버프 지속(초·0=영구)" 스테퍼 추가, 라벨 정정.
- [x] **이동(Teleport) 대상 맵이 숫자 ID로만 표시**
  - 수정: 대상맵 ID 아래에 실제 맵 이름(`→ 속삭이는 동굴`)을 표시. 없는 맵이면
    빨간색 경고.
- [x] **(부수) DB 상세 편집 패널이 화면 밖으로 넘쳐 하단 필드가 안 보임**
  - 증상: 식품처럼 필드가 많은 아이템은 하단(버프 지속 등)이 화면 밖으로 나갔다.
  - 수정: DB 상세 패널을 **마우스 휠 스크롤**(scissor 클리핑) 가능하게 함.

## 범위 밖(미수정) — 이유 명시

- **오디오 볼륨 컨트롤**: `Audio`에 마스터 볼륨 필드/메서드 자체가 없음 →
  "코드엔 있으나 안 보이는" 숨은 기능이 아니라 미구현 신기능이라 이번 범위 밖.
- **다품목 상점**: Shop 이벤트 데이터가 품목 1개만 보유 → 현재 화면도 1품목.
  다품목은 데이터 모델 확장이 필요한 신기능이라 범위 밖.

## 검증

- 셀프테스트 전체 통과.
- 헤드리스 스크린샷 확인: 상점 화면(포션 30G/설명/구입·닫기), 식품 편집기
  버프 지속 스테퍼(스크롤), 이동 이벤트의 대상맵 이름(→ 속삭이는 동굴).
