# 제작 경험 기반 추가 보강 (4차)

큰 맵 이동·여러 맵 제작·늘어난 단축키를 겪으며 느낀 부족함을 리스트로 정리해
전부 구현했다.

## 보강 리스트 (전부 완료)

- [x] **달리기 (Shift)**
  - 문제: 큰 맵(최대 1742²)을 걸어서 이동하기 답답했다.
  - 구현: 이동 중 Shift를 누르면 이동 속도 1.8배 (GamePlayMovement).
- [x] **맵 복제 (새 독립 맵)**
  - 문제: 비슷한 맵을 여러 개 만들 때 처음부터 다시 그려야 했다(전맵뷰어 배치
    복제는 같은 맵을 가리킬 뿐 독립 편집 불가).
  - 구현: World 탭 "맵 복제 (새 독립 맵)" — 타일·충돌·이벤트·타일셋·분위기·BGM·
    조우 설정을 통째로 복사한 **새 편집 가능 맵** 생성(배치 위치는 미배치 기본값).
- [x] **조작 도움말 오버레이 (F1)**
  - 문제: 단축키가 늘어(I/C/J/F2/F3/Shift…) 테스터가 조작을 알기 어려웠다.
  - 구현: 플레이 중 F1로 전체 단축키 표를 표시(다시 F1/ESC로 닫기, 화면 일시정지).

## 검증

- 셀프테스트: 맵 복제(타일/이벤트 깊은 복사) 통과(기존 전부 통과 유지).
- 헤드리스 스크린샷: F1 도움말(이동/달리기/대화/스킬/인벤토리/장비/퀘스트/메뉴),
  World 탭 "맵 복제 (새 독립 맵)" 버튼.
