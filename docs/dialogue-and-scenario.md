# 대화로그 탭 + 스토리 시나리오 탭

## 1. 대화로그(이벤트 대화로그) 탭
라인 1·2·3·4… 를 넉넉히 짜는 분기형 대화 편집기.
- 3열 패널: [대화 목록] [대사 라인 목록] [선택 라인 편집].
- 각 라인: 말하는 이 + 대사. **대답(answer)을 여러 개** 추가.
- 각 대답마다 **대응(response)** 선택: 없음 / 보상(골드·경험·아이템) / 몹소환 /
  적대NPC(시간제한) / 우호NPC(시간제한) / 추종NPC(시간제한 + 대화로 떠나보내기).
  대답마다 "→라인"으로 다른 라인으로 분기 가능.
- 데이터: `Database::dialogues` (entity/Story.h: DialogueScenario/Line/Answer).
- 이벤트 연결: 이벤트 인스펙터의 "대화ID" (Message 이벤트가 이 시나리오를 재생).
- 런타임(GamePlayStory.cpp): Phase::Dialogue — 대사 표시, 대답 버튼 클릭 시 대응 실행
  (보상 지급 / 몹·NPC 소환). 시간제한 NPC는 lifeTimer로 자동 소멸, 추종 NPC는
  Ally+Chase로 따라오고 dismissFollowers 대답으로 떠나보냄.

## 2. 스토리 시나리오 탭 (시퀀서) — 맵 위 시각 편집
장면(scene)별로 동작을 순서대로 배열하는 컷신 시퀀서. **맵을 보면서** 위치·반경·대상을 지정.
- 3열 패널: [장면 목록(검색)] [동작 순서] [배경 맵].
- 동작 종류: 이동 / 대화 / 이펙트 / 등장 / 제거 / 대기.
- **맵 편집 흐름**: 가운데에서 카드의 번호 버튼을 눌러 동작을 *선택* → 오른쪽 맵에서 편집.
  - 이펙트: 맵 클릭 = 발생 중심, 휠 = 반경(타일). 선택 동작은 반경 링으로 표시.
  - 등장·이동: 맵 클릭 = 위치(칸) 지정. 마커 번호로 모든 동작 위치를 한눈에.
  - 제거: 맵 위의 등장(초록) 마커들을 클릭해 **복수 선택/취소**(removeTags). "선택 비우기" 버튼.
  - 이동/대기 대상: 앞선 등장(spawn) 태그를 이름 드롭다운으로 선택(플레이어=0, 대기=전체).
  - 배경 맵은 상단 "배경 맵" 드롭다운으로 변경(Scene::editMapId, 런타임 무관·편집용).
- 데이터: `Database::scenes` (entity/Story.h: Scene/SceneAction; radius·removeTags·editMapId 추가).
- 맵 썸네일은 ensureThumbsForTab()(프레임 RT 밖)에서 생성·캐시.
- 이벤트 연결: 인스펙터의 "시나리오ID 실행" (이벤트 발동 시 장면 재생).
- 런타임(GamePlayStory.cpp): updateScene — 이펙트는 radius에 비례한 크기로, 제거는
  removeTags(+targetId) 전부 처리. 대화 동작은 대화가 끝날 때까지 대기 후 다음으로.

## 3. 모든 목록의 공용 탐색 UX (build 0627a)
데이터가 모이는 모든 탭의 목록에 통일 적용 — 대화·시나리오·DB·캐릭터/몹·NPC·이벤트:
- **검색창**(searchBox): 이름 부분일치(대소문자 무시) 필터.
- **웹 스타일 스크롤바**: 드래그 thumb + 휠.
- **중간버튼 오토스크롤**: 클릭 후 커서를 위/아래로 옮기면 거리 비례 속도로 스크롤
  (다시 클릭/좌우클릭 = 해제). 공용 위젯은 EditorWidgets.cpp(searchBox/autoScroll/scrollbar/nameMatch).
