# 코드만 있고 화면에 없던 것 점검 → 노출(등록)

전체 감사로 "코드는 있으나 화면에 구현/표시되지 않던 것"을 찾아 등록했다.

## 화면에 등록한 것 (코드만 있던 → 이제 표시/동작)

- [x] **지역명 배너 (`Map.name`)**: 데이터에는 맵 이름이 있었지만 플레이 중 어디에도
  표시되지 않았다. → 새 맵 진입(시작/이동/존이동) 시 화면 상단에 지역명을
  잠깐 띄우고 서서히 사라지게 함.
- [x] **액터 온맵 스프라이트 폴백 (`ActorDef.spriteAsset`)**: 에디터에서 지정은
  되지만 게임에서 한 번도 렌더되지 않았다. → 프로젝트 playerSprite가 없을 때
  파티 액터의 spriteAsset을 플레이어 맵 스프라이트로 사용.

## 코드만 있으나 "의도적으로 휴면" (턴제 제거의 잔재 — 되살리지 않음)

이 게임은 실시간 필드 전투이므로 아래 턴제용 코드는 화면에 연결하지 않는다
(요청대로 필드 전투만 유지).
- `src/battle/Battle.*`, `Phase::Battle`, `updateBattle/drawBattle` — 진입 경로 없음.
- `Skill` 구조체 / `db.skills` / `ActorDef.skills` — 턴제 전투 메뉴 전용이라 현재
  필드 전투에선 미사용. (필드 스킬은 `FieldSkill`이 담당)
- `EnemyDef.maxMp`, `Event.battleTurnBased` — 미사용 잔여 필드.

## 이미 화면에 정상 노출 중(오인 방지 확인)

타일 레이어(L1/L2/L3), 어둠/날씨/낮밤, 애니메이션 타일, NPC 전투스탯/HP바,
식품 버프, 인벤토리/장비/퀘스트, 상호작용 마커, 적 스프라이트/드롭, 미니맵 등.

## 검증

- 셀프테스트 전체 통과.
- 헤드리스 스크린샷: 맵 진입 시 "예슈아한민족진리복종마을" 지역명 배너 표시.
