# 숨은 기능 점검 (3차) — 에디터/전투 쪽 미표시 기능

엔진 전 기능을 다시 체크리스트화하고, **코드/데이터에는 있으나 화면에서 만들/볼
수 없던 부분**만 추려 화면에서 동작하도록 했다. 이번엔 주로 **에디터 DB 탭**과
**턴제 전투 화면**을 점검했다.

## 점검 결과: 실제로 화면에 없던 항목 (수정 대상)

- [x] **액터 전투 스킬(`ActorDef.skills`)을 에디터에서 지정 불가**
  - 증상: 턴제 전투의 "스킬" 메뉴가 `ActorDef.skills`를 읽지만
    (`GamePlayMonsters.cpp:289`), DB 탭 액터 편집기엔 스킬 지정 UI가 없었다 →
    스킬을 새로 만든 게임은 전투 스킬 메뉴가 항상 비어 있음.
  - 수정: 액터 편집기에 DB 스킬 목록 **체크리스트**([O]/[ - ]) 추가.
- [x] **적 스프라이트(`EnemyDef.spriteAsset`)를 에디터에서 지정 불가 + 전투화면 미사용**
  - 증상: 필드 몹은 스프라이트를 쓰지만(`GamePlayMonsters.cpp:184`) 에디터에
    선택 컨트롤이 없었고, 턴제 전투 화면은 적을 빨간 사각형으로만 그렸다.
  - 수정: 적 편집기에 스프라이트 선택 버튼 추가. 전투 화면(`drawBattle`)이
    `spriteAsset`이 있으면 실제 적 이미지를 렌더(없으면 기존 사각형).
- [x] **액터 스프라이트(`ActorDef.spriteAsset`) 편집 불가**
  - 수정: 액터 편집기에 스프라이트 선택 버튼 추가.
- [x] **아이템 설명(`Item.description`) 편집/표시 안 됨**
  - 증상: 직렬화되지만 에디터에 입력란이 없고, 인게임 어디에도 안 보였다.
  - 수정: 아이템 편집기에 "설명" 입력란 추가. 인벤토리(I) 호버 시 이름·효과
    요약·설명 표시, ESC 메뉴 아이템 상세에도 설명 표기.

## 점검 결과: 이미 화면에 있는데 오인하기 쉬운 항목 (확인 완료)

- [x] 맵 조우율/조우 적 목록(`encounterRate`/`encounterEnemies`) → 월드 탭
      맵 속성에서 편집 가능(`EditorWorld.cpp:193,223`)
- [x] 이벤트 조건 스위치(`conditionSwitch`) → 이벤트 편집기에 존재
- [x] 스킬 DB(이름/MP/위력/회복) → 스킬 탭에서 편집
- [x] 적 경험치/골드 → 적 편집기에서 편집

## 비고 (의도적으로 손대지 않음)

- `Equipment`(구식 무기/방어구 구조체)의 `iconAsset` 등: 신체부위 아이템
  장비(Item kind==2)로 대체된 레거시 시스템이라 신규 UI를 붙이지 않음.
- 스위치/변수는 이벤트로 설정·조건분기되어 게임에서 정상 동작하며, 별도
  디버그 인스펙터는 범위 밖으로 둠.

## 검증

- 셀프테스트 전체 통과.
- 헤드리스 스크린샷으로 확인: 액터 편집기(스프라이트+전투스킬 체크리스트),
  적 편집기(스프라이트), 아이템 편집기(설명), 전투 화면(적 스프라이트 렌더).
