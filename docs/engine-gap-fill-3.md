# 제작 경험 기반 추가 보강 (3차)

플레이/제작을 더 해보며 느낀 부족함을 리스트로 정리해 전부 구현했다.
(맵 크기 변경은 이미 World 탭에 있어 제외.)

## 보강 리스트 (전부 완료)

- [x] **이벤트 머리 위 상호작용 마커**
  - 문제: 플레이 중 무엇이 말 걸 수 있는/상점/회복/퀘스트인지 알 수 없었다.
  - 구현: 상호작용 가능한(말걸기·조건충족) 이벤트 위에 타입별 마커 —
    퀘스트 `!`(수락가능)/`?`(완료가능), 상점 `$`, 회복 `+`,
    대화/지급/스위치 = 말풍선(···). 가볍게 위아래로 흔들림.
- [x] **새 게임 시작 설정(프로젝트)** — 시작 골드 + 시작 아이템 목록
  - 문제: 새 게임 소지품이 코드에 하드코딩(자동 꾸러미)이라 게임마다 못 바꿨다.
  - 구현: `Project.startGold`/`startItems` + 직렬화. World 탭 "새 게임 시작 설정…"
    모달(골드 스테퍼 + 아이템ID/수량 목록 + 추가/삭제). `newGame`이 적용(미설정
    시 기존 자동 꾸러미 유지). 모든 시작 경로(F5/F6/타이틀/직접실행)에 반영.
- [x] **인벤토리 아이템 버리기** — 우클릭으로 1개 버림(토스트 표시).

## 검증

- 셀프테스트: 새 게임 시작 골드/아이템 적용 통과(기존 전부 통과 유지).
- 헤드리스 스크린샷: 마커(상점 `$`·대화 말풍선), 시작 설정 모달(골드 100·포션×2·
  빵×3), 시작 아이템이 실제 인벤토리에 적용(포션×2/빵×3), 버리기 안내문.
- 샘플 프로젝트에 시작 골드 100 + 포션×2/빵×3 설정.
