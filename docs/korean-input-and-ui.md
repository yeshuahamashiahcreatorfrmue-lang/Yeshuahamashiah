# 한글 입력 · UI 개편 · 전맵뷰어 줌

요청 5종을 구현했다.

## 1. 한글 입력 (모든 이름 필드)
- **버그 원인**: `ui::textField`가 코드포인트 32–125(ASCII)만 받아 한글을 거부했다.
- **수정**: 모든 유니코드 코드포인트를 UTF-8로 인코딩해 입력, 백스페이스는 UTF-8
  한 글자(연속 바이트 포함)를 통째로 삭제. → 아이템·캐릭터·이벤트·이펙트·맵 등
  모든 `textField`에서 한글 입력 가능.
  - `src/render/UI.cpp` textField
- **폰트**: 입력한 어떤 한글도 렌더되도록 폰트에 현대 한글 음절 전체(가–힣 11,172자)
  + 호환 자모를 베이크(48px, 8192×4096 아틀라스). 기존엔 소스에 등장한 글자만
  베이크해 임의 입력 글자가 깨졌다.
  - `src/core/Text.cpp` LoadUIFont

## 2. 한글 IME 상태에서도 WASD 이동 (+ 타 국가 자판)
- **원인**: 한글 입력기(IME)가 켜져 있으면 W/A/S/D 키가 조합용으로 가로채여
  게임에 전달되지 않는다.
- **수정**: 텍스트 필드가 포커스됐을 때만 IME를 켜고, 그 외(플레이/타이틀/에디터 일반)
  에서는 IME를 꺼서 키가 그대로 전달되게 했다. → 입력 언어가 한국어여도 WASD·단축키
  정상 동작, 필드에선 한글 입력 가능.
  - `src/core/Platform.{h,cpp}` setImeEnabled (ImmAssociateContext, Windows 전용)
  - `editor/Editor.cpp`(필드 포커스 시 on), `game/GamePlay.cpp`(플레이 중 off),
    `game/TitleScreen.cpp`(IP 입력 시만 on)
  - CMake: Windows에 `imm32` 링크
- **타 국가 자판**: raylib/GLFW의 키 코드는 자판 배열과 무관하게 **물리적 위치** 기준
  이라, AZERTY 등에서도 WASD 위치의 키가 그대로 이동키로 인식된다(별도 처리 불필요).

## 3. 전맵 뷰어 — 100%=1742, Ctrl+휠 줌, 전체 보기
- 각 맵 박스를 **실제 타일 크기 비례**로 표시(1742×1742 = 셀 100%, 작은 맵은 비례 축소).
- **Ctrl+휠(및 휠)** 로 확대/축소(0.02×–3.0×, 곱셈 줌)로 1742 월드도 한눈에.
- 우상단 `- %  +  전체 보기` 컨트롤, **전체 보기**는 배치된 모든 맵을 화면에 맞춤.
- 전역 Ctrl+휠(UI 배율)은 전맵뷰어에서 양보(`Editor::wantsCtrlWheel`).
  - `src/editor/EditorWorld.cpp`, `src/core/Engine.cpp`, `src/editor/Editor.{h,cpp}`

## 4. 캐릭터창 키 C→O, C 제거
- 장비/캐릭터 창 단축키를 **O**로 변경, **C는 제거**(스킬과 혼동 방지).
  - `game/GamePlayMovement.cpp`, HUD 버튼/도움말/안내문 일괄 변경

## 5. I 인벤토리 + O 캐릭터창 병렬·소형 패널
- 전체 화면을 덮던 오버레이를 **좌측 인벤토리 / 우측 캐릭터** 2단 소형 패널로 재설계.
  서로 닫지 않고 동시에 열려 한눈에 비교 가능, 주변 게임 화면도 보임.
- 캐릭터 패널: Lv/EXP/체력/기력/공·방·속 + 신체부위 장비 실루엣(슬롯 클릭=해제).
  장착은 인벤토리에서 장비 클릭.
  - `src/game/GamePlayRender.cpp` drawInventoryOverlay/drawEquipOverlay
