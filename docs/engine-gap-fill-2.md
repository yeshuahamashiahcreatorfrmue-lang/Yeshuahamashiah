# 제작 경험 기반 추가 보강 (2차)

이벤트/맵을 더 만들며 느낀 부족함을 리스트로 정리해 전부 구현했다.

## 보강 리스트 (전부 완료)

- [x] **이벤트 목록 패널** (이벤트 탭 좌측)
  - 문제: 큰 맵에서 이벤트를 편집하려면 타일을 일일이 찾아 클릭해야 했다.
  - 구현: 맵의 모든 이벤트를 "#id 종류 @x,y"로 나열(스크롤). 클릭하면 선택 +
    카메라가 그 이벤트로 이동.
- [x] **현재 맵에서 바로 플레이테스트 (F6 / "이 맵 테스트" 버튼)**
  - 문제: F5는 항상 시작맵부터라, 특정 맵/이벤트 확인이 번거로웠다.
  - 구현: `Engine::startPlaytestAt` — 편집 중인 맵의 가장 가까운 통행 가능 타일에서
    바로 플레이 시작.
- [x] **적 처치 아이템 드롭** (`EnemyDef.dropItemId` / `dropRate%`)
  - 구현: 적 편집기에 드롭 아이템·확률 필드. 필드 처치/턴제 전투 승리 시 확률로
    드롭(획득 토스트/로그). 직렬화.
- [x] **회복 지점 이벤트** (`EventType::Heal`)
  - 구현: 9번째 이벤트 종류. 파티 전체 체력·기력·포만·수분 완전 회복(여관/세이브
    지점용). 오브젝트 팔레트에도 "회복 지점" 추가.

## 검증

- 셀프테스트: 회복 이벤트 타입·적 드롭 직렬화 통과(기존 전부 통과 유지).
- 헤드리스 스크린샷: 이벤트 목록 패널(총 18개), 9종 그리드의 "회복", 적 편집기
  드롭(아이템 1→포션, 확률 30%), 툴바 "이 맵 테스트(F6)" 버튼.
- 샘플 적(슬라임/박쥐/멧돼지)에 드롭 설정 추가.
