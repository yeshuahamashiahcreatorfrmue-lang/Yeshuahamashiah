# 전체 기능 점검 체크리스트 (윈도우 빌드 동일 렌더 경로)

대화 전체에서 구현한 모든 기능을 윈도우 .exe와 동일한 raylib 렌더/로직 경로
(헤드리스 GL: GALLIUM_DRIVER=llvmpipe + xvfb)로 하나씩 점검했다.
※ 실제 Windows .exe는 CI(windows-build.yml)가 동일 소스로 빌드/스모크테스트하며,
플랫폼 계층(Winsock/파일다이얼로그)만 분기됨 — 화면/로직 코드는 동일.

## 에디터 (8개 탭) — 전부 정상
- [x] 월드: 맵 목록·미리보기·크기변경·조우/날씨/어둠/낮밤/BGM·시작맵·맵복제·새게임 시작설정
- [x] 전맵뷰어: 맵 썸네일 그리드 + 목록(배치/드래그/복제/삭제)
- [x] 맵: 도구(펜/지우개/채우기/사각형/스탬프/충돌/오브젝트)·레이어 L1/L2/L3·줌·팔레트
- [x] NPC: NPC·몹·플레이어 목록 + 플레이어 데이터(HP/GP/공방속/포만/수분/차지칸수)
- [x] 이벤트: 목록+필터·종류 그리드(9종)·종류별 필드·드래그·복사/붙여넣기·효과음·조건·다중지급·비활성/좌표
- [x] 캐릭터: 빌더(모션/방향프레임/칸수/필드스킬)
- [x] 에셋: 타일셋/스프라이트 목록·가져오기·AI 컷아웃·BGM 가져오기
- [x] DB: 3분류(아이템/액터/적)·식품/장비 필드·스크롤
- [x] 툴바: 저장·플레이(F5)·이 맵 테스트(F6)·빌드태그

## 미리보기 오버레이 — 전부 정상
- [x] 마커(이벤트/NPC/입구/존통로)·정보박스·이동·범례
- [x] 우측 오브젝트 편집 패널: 프리셋 추가 + 목록 삭제

## 플레이 — 전부 정상
- [x] 이동(WASD/방향키)·달리기(Shift)·필드 실시간 전투(턴제 없음, "적이 나타났다!")
- [x] 스킬바(Z/X/V/F/G)·생존 바(포만/수분)·식품 시간제 버프 배지
- [x] 인벤토리(I, 분류/우클릭 버리기)·신체부위 장비(C)·퀘스트 일지(J)
- [x] 상점(다품목, 골드 게이팅)·대화창(이름표/초상화/자동줄바꿈/4지선다)
- [x] 지역명 배너·상호작용 마커(!/?/$/+/말풍선)·미니맵
- [x] ESC 메뉴: 아이템/장비/상태/설정(음량)/저장(3슬롯)
- [x] F1 도움말·F3 스위치/변수 인스펙터·F2 에디터 전환
- [x] 타이틀: 새 게임/이어하기/MMO 호스트(42)/접속/에디터
- [x] 시작 골드·아이템 적용(골드 100, 포션×2/빵×3)

## 자동 검증
- [x] 셀프테스트 99/99 통과(직렬화·퀘스트·전투·인벤토리·이벤트 조건 등)
- [x] 200프레임 오토워크 스모크(이동/전투/인카운터) 정상 종료(rc=0, 예외 없음)
