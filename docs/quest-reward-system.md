# NPC 퀘스트·보상 시스템 + 이벤트 패널 개편 (상용형)

이벤트 패널을 상용 RPG처럼 **종류별로 정리된 탭 그리드**로 개편하고, NPC가
의뢰를 주고 → 진행도가 추적되고 → 보상을 받는 **퀘스트·보상 체계**를 처음부터
끝까지 구현했다. 사용자는 한 패널에서 **종류 선택 → 안내문 몇 자 입력 →
완료 조건·보상 선택**만 하면 퀘스트 NPC가 완성된다.

## 이벤트 패널(에디터) 개편

- 이벤트 종류를 **2열 라벨 그리드**로 한눈에: 메시지 / 이동 / 아이템지급 /
  스위치 / 전투 / 상점 / 퀘스트·보상 / 엔딩 (선택 항목 강조).
- 트리거(말걸기/접촉/자동실행)도 버튼 3개로 명확히.
- 종류별로 필요한 입력만 표시. 길어지는 패널은 **마우스 휠 스크롤**.
- 이동(Teleport)·퀘스트 대상은 ID 옆에 **실제 이름**(맵/적/아이템) 표시, 없는
  대상이면 빨간 경고.

## 퀘스트·보상 체계 (처음~끝)

데이터는 이벤트에 자체 포함(별도 등록 테이블 불필요). 완료 조건 4종:
- **즉시 지급(대화)**: 말 걸면 바로 보상. (보상이 없으면 단순 목표 안내문)
- **몬스터 처치**: 대상 적ID(-1=아무거나) × 처치 수. 필드/전투 처치가 자동 집계.
- **아이템 수집**: 대상 아이템ID × 수량. 제출 시 회수 여부 선택.
- **지역 도달**: 대상 맵ID에 진입하면 달성.

보상: **골드 / 경험치 / 아이템(+수량)**. 완료 문구(questDoneText) 지정 가능.

진행 흐름:
1. NPC에게 말 걸기 → 의뢰 수락(안내문 표시, HUD 목표 갱신).
2. 사냥/수집/이동으로 진행 (처치·도달은 맵이 달라도 추적, 수집은 인벤토리 기준).
3. 다시 말 걸기 → 조건 충족 시 **보상 지급 + 완료**, 미충족 시 진행도 안내.

UI:
- HUD 상단 목표줄이 활성 퀘스트 진행도로 갱신("슬라임 0/3 처치").
- **퀘스트 일지**(J 키 / 하단 "퀘스트(J)" 버튼): 진행/완료 목록 + 조건별 진행도.
- 보상 수령 시 토스트 + 메시지("퀘스트 완료! 보상을 받았다 | 골드 +120 …").
- 세이브/로드에 퀘스트 상태 직렬화.

## 코드 위치

- `src/entity/Event.{h,cpp}`: 퀘스트/보상 필드 + 직렬화.
- `src/game/GameState.{h,cpp}`: `QuestState`, `quests` 맵, `addKillProgress`/
  `markReached`, 직렬화.
- `src/game/GamePlayEvents.cpp`: `runQuestEvent`/`questObjectiveMet`/
  `questProgressText`/`grantQuestReward`/`refreshQuestObjective`/`drawQuestLog`.
- 훅: `onMonsterKilled`/`onNpcKilled`(처치), `loadMap`(도달), 인벤토리(수집).
- `src/editor/EditorEvents.cpp`: 종류 그리드 + 퀘스트 편집 + 스크롤.
- 샘플: `maps/1.json`에 퀘스트 NPC 2종(슬라임 처치·빵 수집).

## 검증

- 셀프테스트(처치 집계/필요수량 캡/도달/아무거나/세이브로드) 통과.
- 헤드리스 스크린샷: 이벤트 패널(퀘스트·보상 그리드+완료조건+보상),
  퀘스트 일지(진행 2건/조건별 진행도), 보상/안내 메시지 표시.
