# 이벤트 "각 7개씩" 제작 경험 기반 보강 (2차)

## 보강 리스트 (전부 완료)

- [x] **발동 조건 확장: 아이템 보유 / 골드 이상**
  - 문제: 조건이 스위치/변수뿐이라 "열쇠가 있어야 열리는 문", "N골드 이상" 같은
    게이팅을 만들 수 없었다.
  - 구현: `conditionItemId`+`conditionItemCount`, `conditionGold`. `eventConditionMet`이
    인벤토리/골드를 검사. 에디터 발동 조건 섹션에 추가.
- [x] **아이템 지급 다중화**
  - 문제: 한 이벤트로 아이템 하나(+골드)만 줄 수 있어 보물상자 구성이 빈약했다.
  - 구현: `Event.giveItems[]` (id,count 목록). 단일 itemId/amount/gold에 더해 여러
    아이템을 한 번에 지급(음수=회수). 에디터 목록 편집(추가/삭제).
- [x] **이벤트 비활성화 토글 + 좌표 직접 입력**
  - 문제: 테스트 중 이벤트를 잠깐 끄거나 정확한 칸에 두기 번거로웠다.
  - 구현: `Event.enabled`(꺼지면 발동 안 함, 목록에 `[off]` 표시) + 인스펙터
    X/Y 위치 스테퍼(정밀 배치).
- [x] **이벤트 목록 종류 필터**
  - 문제: 한 맵 이벤트가 많아 특정 종류만 보기 어려웠다.
  - 구현: 목록 상단 "필터: 전체/메시지/이동/…" 순환 버튼으로 종류별 추리기.

## 검증

- 셀프테스트: 조건(아이템/골드/비활성) 게이트 + 다중 지급 직렬화 통과
  (기존 전부 통과 유지).
- 헤드리스 스크린샷: GiveItem 추가 아이템 목록, 발동 조건(아이템/골드)·배치/상태
  (X/Y/사용 토글), 목록 "필터: 전체" 버튼.
