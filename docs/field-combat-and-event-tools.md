# 턴제 폐지(필드 전투) + 이벤트 제작 도구 보강

## 1. 모든 전투를 필드 소환(대화 후 교전)으로

이 게임은 턴제가 아니라 실시간 필드 전투다. 턴제 전투 화면을 통한 진입을 모두
필드 소환으로 바꿨다.

- [x] **랜덤 인카운터 → 필드 소환**: `startEncounterBattle`/`startBattleWith`가
  턴제 화면을 열지 않고 플레이어 주변 빈 타일에 적을 소환(실시간 교전).
- [x] **전투 이벤트(StartBattle) → 필드 소환 + 대화 후 교전**: `battleTurnBased`
  분기 제거. 적을 이벤트 옆에 소환하고, 대사(text)가 있으면 소환 직후 표시 →
  "대화 후 교전". 혼합 적 구성/처치 스위치 유지.
- [x] **필드 몹 상시 스폰 복원**: `encounterRate>0` 맵도 평소에 필드 몹이
  돌아다니도록(turn-based 전용 분기 제거).
- [x] 에디터 전투 이벤트에서 "턴제/필드" 토글 제거 → "필드에 적을 소환" 안내.

## 2. 이벤트 제작 도구 (각 7개씩 제작 경험 기반)

- [x] **이벤트 드래그 이동**: 이벤트 탭 캔버스에서 마커를 끌어 빈 타일로 위치 변경.
- [x] **이벤트 클립보드 복사/붙여넣기(맵 간)**: 인스펙터 "복사(클립보드)" →
  다른 맵의 목록에서 "여기 붙여넣기".
- [x] **이벤트별 효과음**: `Event.sfx` — 실행 시 지정 효과음 재생.
  인스펙터에서 기본/select/coin/levelup/defeat/slash/magic/boom 순환.

## 검증

- 셀프테스트 통과(이름표/효과음/4지선다/혼합전투/대화 진행 직렬화 포함).
- 헤드리스 스크린샷: 전투 트리거 시 적이 필드에 소환(턴제 화면 없음),
  인스펙터의 효과음/선택지 A~D 버튼.
