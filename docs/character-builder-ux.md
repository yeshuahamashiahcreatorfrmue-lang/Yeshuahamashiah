# 캐릭터 빌더 사용성 점검 체크리스트

샘플 캐릭터 3종(용사/기사/궁수)을 빌더로 만들어보며 발견한 불편 사항과 수정 계획.
`[x]` = 수정 완료.

## 빌드해보며 느낀 불편 → 수정
- [x] **프레임 순서 변경 불가**: 클릭으로 끝에만 추가되고 지우기만 됨. 잘못 넣으면
      지우고 다시 넣어야 함 → 프레임 **선택 후 ◀ 이동 / ✕ 삭제 / ▶ 이동**.
- [x] **모션 비우기 없음**: 처음부터 다시 만들려면 한 칸씩 삭제 → **"비우기"** 버튼.
- [x] **캐릭터 복제 없음**: 비슷한 캐릭터 여러 개 만들 때 반복 작업 → **"복제"** 버튼.
- [x] **스트립/시트 통짜 추가 문제**: 애니 스트립(예: 6프레임 이펙트, 움짤 GIF)을
      클릭하면 통째로 1프레임이 됨 → **"N분할 추가" 모드 + 분할수**(애니 에셋은
      프레임 수 자동 인식).
- [x] **프레임 썸네일 한 줄 고정**: 많아지면 패널 밖으로 잘림 → **여러 줄 줄바꿈**.
- [x] **걷기 비어있는데 플레이어 지정 가능**: 인게임에서 안 보임 → **경고 안내**.

## 검토 후 유지 (현 상태 적절)
- 라이브러리에 모든 이미지(타일셋 포함) 노출: 어떤 이미지든 프레임 재료로 쓸 수
      있게 의도. 분할/선택은 사용자 판단.
- 모션 6종 고정(걷기/공격/스킬1/스킬2/궁극기/죽음): 시전 슬롯 매핑과 일치.

## 결과물
- 샘플에 3종 캐릭터 수록: 용사(파랑, 표준) · 기사(빨강, 느리고 묵직) · 궁수(초록, 빠릿).
  각각 6모션 전부 채워진 상태로 동작, fps로 무게감 차등.
