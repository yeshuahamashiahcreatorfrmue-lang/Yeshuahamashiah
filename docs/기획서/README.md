# 예슈아 월드맵 전쟁 — 기획서

모바일 세로형 **월드맵 RTS + 개인 RPG** 하이브리드. 단일 파일(`index.html`, 캔버스 + 바닐라 JS)로 동작하는 프로토타입.

대륙에서 **8세력 + 충성 장수 + 무소속 개인**이 성을 두고 다툰다. 성을 가진 자만 병력을 생산하는 '세력'이 되고, 모든 성을 잃으면 떠도는 '개인'이 된다. 개인이 첫 성을 점령해 **궐기**하면 `예슈아한민족진리단일국가`로 거듭난다.

## 구현 현황
- ✅ 월드맵·이동·항해·정착지·점령·궐기
- ✅ 9세력 슬롯(플레이 7 + 궐기 1 + 적대 1 별도)
- ✅ 17 병종 + 병종 상성/원거리/회복/지형/포위 전투
