# 11. 무역 · 해상 (설계 기획)

> 이 문서는 **기획(설계 의도)** 기준이다. 각 항목에 구현 현황(✅완료 / ⏳미구현 / 🟡일부)을 표기.

## 운반체
| 운반체 | 영역 | 거점 | 역할 | 현황 |
|---|---|---|---|---|
| 🐎 기마병참원 | 육상 | 기마무역소 | 무역소 간 화물 왕복(자동) | ✅ |
| 🛥 유람선 | 해상 | 항구 | 항구 간 무역 + 개인 도하(ferry) 제공 | ✅ |
| ⛴ 수송선 | 해상 | 항구(승선모드) | 육군 도하 | ✅ |
| ⚓ 전함 | 해상 | 조선소 | 해상 전투/순찰, 교역선 약탈 | ✅ |
| 🐎 기마병참대 | 육상 | 기마무역소(편성) | **기마병참원의 수송량 증가**(호위/보급 부대) | ⏳ |

## 기마무역소 편성 (기병 전용) — ⏳ 미구현
- 기마무역소(tradePost)에서 **기마병참원 + 기마대**를 하나로 **묶을 수 있다**.
- 묶을 수 있는 병종은 **기병류 병종만**(보병·궁병 등 불가).
- **기마병참대** 유닛 = 기마병참원의 **수송량을 증가**시키는 편성 부대.

## 기마병참원 수송량 보정 (cargoMul) — 🟡 식만 존재
- **100명당 +10%** 수송량 증가. (편성된 기마병참대/호위 병력수 기준)
- 상한 = 기마병참원 수송량 **4200%**(=42배).
- 식: `cargoMul = 1 + min(41, floor(escort/100) × 0.1)` (코드에 자리만 있고 `escort` 주입 미구현 → 현재 항상 1배).

## 무역 루프 ✅
1. **적재**: 빈 운반체가 다른 거점으로 가 화물 적재.
   - 화물량 = `(20 + 모항거리×0.05) × 약탈배수 × cargoMul`.
2. **귀환**: 자기 세력 거점 도착 시 `gold[team] += 화물`.

## 약탈 ✅
- 적 세력 거점에서 적재 = 화물 **×1.6**.
- 전함이 **적재한 교역선/수송선 격침** 시 `gold += 화물×0.5` 노획.

## 도하/승선 ✅
- 육군이 물에 들어가려면 승선 필요: 자기 항구 승선모드(수송선/전함) 또는 유람선 ferry(`ferryUntil`).
- 항구·ferry 둘 다 없으면 물 진입 불가.

## 시설
- **항구**(해안 전용): 도하 거점, 승선모드 전환, 유람선 정원(최대 7).
- **조선소**(항구 위): 전함 건조(세력당 최대 2).
- **기마무역소**: 육상 교역(기마병참원) 거점 / (⏳ 기마병참대 편성 거점).

## 함선 전투력 ✅
- 전함(해군) `×1.42`, 수송선 `×0.35`, 유람선/교역선 0(비전투). 물 위 비-해군 부대 ×0.85.
