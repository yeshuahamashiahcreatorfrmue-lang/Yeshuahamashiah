# 01. 세계관 · 컨셉 · 전체 루프

## 테마
- **예슈아(예슈아하마쉬앟)** 신앙을 중심에 둔 세계. 참 선지자 예슈아의 백성이 빛으로 대륙을 통일하는 것이 정통 노선.
- 천주교적 우상숭배·원소숭배 맥락은 배제. 세력 이름·영웅 이름은 **순우리말 + 고대 한국어 느낌**.
- 거짓 세력(거짓 교단)은 **타락한 악마를 섬기는 거짓 선지자**의 빌런으로만 등장(플레이 불가, [02 참고](02_세력.md)).

## 핵심 규칙
- **성을 가진 자 = 세력**: 병력을 생산(양성)할 수 있다.
- **성을 모두 잃으면 = 개인**: 떠도는 군주가 된다.
- **개인이 첫 성 점령 = 궐기**: `예슈아한민족진리단일국가`(7번 세력)로 편입되어 거듭난다.
- 물(바다/강)은 **항구**가 있어야 건넌다(승선/유람선).

## 승패
- 플레이어 군주 부대(troops)가 0이 되면 **패배**(게임오버, 생존 시간 표시).
- 대륙의 모든 성을 한 세력이 차지하면 통일(종료).
- 전투·경제는 실시간 진행.

## 전체 게임 루프
1. **세력 선택**(플레이 가능 7세력) → 영웅 군주로 시작.
2. **월드맵**에서 부대 이동·교전·정착지 점령.
3. **개인 관여 교전** 발생 시 → [전술 존 전투맵](05_전술존.md)으로 진입(직접 지휘).
4. 점령한 성에서 **양성(병종 생산)** · 수도성에서 **예슈아화 발행**.
5. 정착지 근처 **상점**에서 개인 예슈아화로 장비 구매([07](07_마켓_아이템.md)).
6. 패망하면 개인으로 강등 → 재점령 시 **궐기**로 진리국 편입.
