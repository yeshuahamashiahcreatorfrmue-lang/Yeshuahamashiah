# 06. 경제 (금화 vs 예슈아화)

## 두 화폐
| | 금화(세력 자원) | 예슈아화(coin) |
|---|---|---|
| 보유 주체 | 세력 단위(`gold[team]`) | 개인 단위(`unit.coin`) + 세력 금고(`coinPool[team]`) |
| 용도 | 병종 양성 장비비, 시설 건설 | 개인 상점 구매, 세력 간 유통 |
| 발행 | 수도성에서 금화로 발행(`MINT_COST=30 → MINT_PULSE=42`) | 위 발행 + 개인 벌이 |

- 시작값: 세력 `gold=120`, 무소속 `gold=40`.

## 양성 (병종 생산)
- 정착지는 병영(`barracks`)으로 **인력(reserve)** 충원: `reserveMax = 2000 + barracks×1500`, 초당 `barracks×BR(9)`.
- 양성 1펄스 = `TRAIN_PULSE=420` 병력. 조건: `reserve≥420` & `gold≥EQUIP[병종]`.
- 결과 병력은 같은 병종 아군 부대에 합류(없으면 정착지서 스폰, 부대수 상한 `ARMY_CAP=7`). 부대 상한 `capMax = 2000 + 병영합×4000`(세력 아닐 시 1500).
- **AI 병종 다변화**(`aiPickType`): 보유 금화로 감당되는 병종을 가중 랜덤 양성(보병 baseline + 기병/궁병/소총/기갑/포병/자주포/예슈아대 + **자세력 특수** 우대). 금화 income(농지)으로 지속 충당.
- 플레이어는 **2단 훈련 라디얼**로 병종 선택+속도 조절([09 참고](09_맵_UI.md)).

## 예슈아화 발행/유통 (`shopTick`)
- 무소속 개인은 지역 교역으로 초당 8 적립, 42 모이면 가까운 **타 세력 가게**에 지불 → 그 세력 `coinPool` 귀속.
- 개인 간 예슈아화 거래(부유한 개인→가까운 개인 일부 이전).
- **플레이어 지도자 봉록**: 보유 성 수에 비례해 예슈아화 적립(`3 + 보유성수` /초).
- **처치 노획**: 적 처치 시 `coin += min(80, 적병력×0.02)`.

## 무역/해상 경제 → 상세 [11_무역_해상.md](11_무역_해상.md)
- **육상 교역**(기마병참원/무역소) + **해상 교역**(유람선/항구): 거점 왕복 적재→귀환 시 세력 금화 수익.
- **약탈**: 적지 거점 적재 ×1.6, 전함이 적재 교역선 격침 시 화물 ×0.5 노획.
- **도하/승선**: 항구 승선모드(수송선/전함) 또는 유람선 ferry로 육군이 물을 건넌다.
- 함선: 기본 전투력 `SHIP_BASE=1700`, 해군 ×1.42(`NAVY_BONUS`), 승선거리 `BOARD=95`, 재출항 쿨다운 `PCD=10`.

## 시설 비용 (`COST`)
- 병영 `60×레벨`, 농장 `50×레벨`, 항구 90, 조선소 160, 여객(유람선 정원) 70, 교역소 40.
