# 05. 병종

## 공통 병종 [#25] (+ 초기 보병/기병/궁병/소총병/기갑 [#16~#19])
| 병종 | 성격 |
|---|---|
| 보병 | 저렴한 기본 인력. 훈련소 양성 원료. 기병에 약함 [#18][#19] |
| 기병 | 보병을 박살. 이동 빠름(돌격) |
| 궁병 | **상성 아닌 원거리 포격 전담**(별도 차감식) [#17] |
| 소총병 | **기병에 강함** [#18] |
| 기갑(전차) | 중장갑, 느림, 원거리 포격 피해 절감 [#19] |
| 포병 | 공성 원거리 |
| 자주포병 | 기동 공성 원거리 |
| 예슈아대 | **근처 아군 병력수 회복**(비전투 지원) [#25] |

## 세력 특수병종 [#25]
- **7세력 각 1종**(팔방미인 올라운더, 하나만 찍어도 대부분 상황에 쓸만한 독특 유닛). 세력 영웅이 사용.
- 예슈아한민족국=예슈아한민족대 / 밤마루=밤기마 / 노을=노을활잡이 / 눈벌=눈보라꾼 / 푸른들=들풀지기 / 큰물=물너울대 / 무쇠=무쇠벼리.
- 궐기국(진리단일국가)=**예슈아행하기위해죽지않음지옥** / 적대세력=거짓사제.

## 훈련소 양성 [#20]
- **보병이 훈련소에 들어가 장비·훈련을 받으면** 다른 병종 유닛 수가 생산되어 증가.
- 즉 보병(인력)=원료 → 금화(세력 자원)로 장비비를 치러 원하는 병종으로 전환.
