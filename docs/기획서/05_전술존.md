# 05. 전술 존 전투맵 (Zone)

플레이어 군주가 **직접 관여하는 교전**이 발생하면 별도의 전술 전투맵으로 진입(`detectPlayerBattle` → `enterZone`). 월드 추상 전투와 달리 병력이 **블록(군집)**으로 쪼개져 실시간 교전.

## 진입/구성
- 군주 인접에 적 부대 접촉 시 진입. 주변 240 내 아군/적 부대(각 최대 6) 참전.
- 부대 troops를 블록(`ZBLK=420`/블록, 부대당 최대 24블록)으로 분할.
- 군주(개인)는 단일 아바타로 직접 이동 지령(탭). `ZSPD=64`.

## 지형 반영
- 교전 지점의 월드 지형(`terrAt`)을 존맵에 반영: **배경색** + 이름(HUD) + 엄폐 피해배수(`terrDef`) + 이동속도(`terrSpd`).
- 지형: 바다·강·사막·평지·초원/숲·진흙·산맥·설산 ([10_상수표](10_상수표.md) TERR).

## 해안 상륙 존
- 해안/해상 교전(지형 물 또는 해안 셀, 또는 승선 부대)일 때 **상륙전** 모드.
- 상단에 **바다 띠 + 해안선 + 상륙 함선** 묘사, "🌊 상륙 해안" 표기.
- 물 띠(`seaY`)를 건너는 병력·군주는 **이동속도 ×0.5**(상륙 페널티 → 해안 사수 성립).

## 전술 차감 산식 `zoneDamage`
```
raw = atkBlocks(공) - atkBlocks(방)×0.5  (최소 0.05)
raw ×= tacAtk(공,방) × tacDefMul(방,공)         // 04와 동일 병종 상성
보병(방) 진형: 포위 시 ×0.23(TAC_DEF, 라인 사수) / 정지+비기병 ×0.58(−42%)
그 외(방): 포위 시 ×1.42(추가 총감소)
적용: troops -= raw×42×0.5×dt×0.55×terrDef (군주는 ×gearAtk/gearDef)
```

## 진형/기동 전술
- **포위**: 적 블록 3기 이상 인접 시 가중(보병은 역으로 사수).
- **기병**: 이동 ×1.5(돌격), 기갑 외 전부에 공격발동.
- **원거리(궁/포/자주포)**: 7초마다 일제사격(`zRange`로 사거리 유지·카이팅). 포병은 느림(×0.5).
- **예슈아대**: 같은 진영 블록/군주 회복(사거리 74, 초당 46), 비전투.
- **군주 자동 교전**: 이동 지령 없으면 최근접 적으로 자동 진격.

## 종료
- 군주 병력 0 → 패배 / 적 블록 전멸 → 승리 / 80초 초과 → 양측 이탈(교착 방지).
- 결과 병력을 원래 부대에 동기화(`exitZone`). 재진입 쿨다운 `zoneCD=3.5`.

## 표시
- 블록 테두리색 = 병종별(`ZTCOL`). 군주=흰 테두리 원 + 병력수. 상단 아군/적 총합, 후퇴 버튼.
