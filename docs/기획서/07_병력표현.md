# 07. 병력 표현 (간소화) [#8][#9]

병력은 개개인을 그리지 않고 **군집(cluster)**으로 간소화 표시한다.

## 규모 단위 [#8]
**42 · 420 · 4200 · 42000 · 420000 · 4200000** 명 단위.
- 각 군집을 **크기 · 색깔 · 형태 · 병종 · 세력깃발**로 구분.
- 월드맵 위에서도, 실제 필드(전술 존)에서도 동일하게 간소화 표시.

## 표시 규칙 [#9]
- **규모별 외곽 링은 쓰지 않는다.**
- 대신 **군집 크기 + 그 위에 명확한 수치(숫자)**로 표현.
- 색=세력색, 형태/아이콘=병종, 위에 깃발/수치.

## 구현 현황
- 군집 크기·색·병종·세력 표시 + 수치 라벨 ✅ (외곽 링 없음)
- 6단계 규모 스케일(42~4,200,000) 표기 체계 🟡 (현재 수치 라벨로 표현, 단계별 아이콘 스케일은 단순화)
