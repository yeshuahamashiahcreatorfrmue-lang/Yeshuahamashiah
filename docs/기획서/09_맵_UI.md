# 09. 맵 렌더링 · UI · 조작

## 월드맵
- 크기 `WORLD_W×WORLD_H = 1280×1920`. 격자 `GCELL=24`.
- 지형 배경(`bg`), 영역 틴트(`terrLayer`), 국경 실선(`borderPath`), 정착지/유닛 순으로 렌더.
- 카메라: 핀치 줌(`cam.zoom`, min~max), 드래그 패닝, 미니맵 탭/드래그 이동.

## 세력색 + 국경선 (지도식)
- **세력색**: 셀당 1px 저해상 버퍼(`tFill`)에 소유색 칠 → 보간 업스케일(부드러운 면, alpha 0.22). 픽셀 격자 제거.
- **국경선**: 서로 다른 세력 셀 사이 격자 변을 수집 → 폴리라인 추적 → **Chaikin 곡선 스무딩(2회)** → `Path2D`(월드좌표) 캐시.
  - 매 프레임 실선 스트로크(밝은 케이싱 `3.4/zoom` + 어두운 선 `1.4/zoom`). 지도처럼 또렷.
- **갱신 시점**: `renderTerritories`는 **점령 시에만** 실행(캐시) → 매 프레임 부하는 Path2D 스트로크뿐. 최적화 양호.

## 미니맵 (우하단)
- 지형 + `tFill`(세력색) + `borderPath`(국경 실선) + 정착지/유닛 점 + 시야 사각형.

## 세력 깃발/엠블럼
- **예슈아 진영(0·7)**: 예슈아하마쉬앟 성표(8각 광채 별, `drawCrest`).
- **그 외**: 세력명 **앞 세 글자** 텍스트(`factionTag`). 부대 깃발 옆 + 정착지 아래.

## 2단 훈련 라디얼
- 정착지 길게 끌기 → 방향=병종, 거리=양성 속도.
- **안쪽 링(거리<112)**: 기본 병종(보병·기병·궁병·기갑·자세력 특수).
- **바깥 링(거리≥112)**: 고급(소총병·포병·자주포병·예슈아대 + 수도성 💰 발행).
- 경계 원 표시, 멀수록 빠르고 고급. 라벨에 병종·펄스·장비비·속도 표기.

## 조작 요약
- 탭/드래그: 군주 부대 이동 목표 지정.
- 정착지 탭: 자기 성=마을 패널(시설 업그레이드)/길게=훈련 라디얼.
- 🛒 상점 버튼: 정착지 근처에서 개인 마켓.
- 전술 존: 탭=군주 이동 지령, 후퇴 버튼=이탈.

## HUD
- 세력·영웅명, 레벨/경험치 막대, 병력 막대, 금화 💰예슈아화, 보유 성 수, 병종·지형(엄폐 🛡/노출 ⚠, 승선 ⚓).
