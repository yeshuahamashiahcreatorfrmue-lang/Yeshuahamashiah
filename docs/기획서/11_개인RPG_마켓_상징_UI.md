# 11. 개인 RPG · 마켓 · 상징 · UI

## 영주(영웅) RPG [#13]
- 세력 영주 = 개인 플레이어 같은 캐릭. 탭 이동 + 자동 교전. 성을 가지면 RTS 부대 지휘가 더해짐.
- 처치 노획·지도자 봉록으로 개인 예슈아화 적립.

## 개인 예슈아화 마켓 [#26]
- 정착지 근처에서 **🛒 상점** 오픈. 개인 예슈아화로 장비/보급 구매, 지불금은 그 세력 자산으로 귀속.
- 아이템 예: 명검(공격+15%)·흉갑(피해−12%)·준마(이동+18%)·군량(병력+1800)·야전병원(회복). (천주교색 '성물'은 제외 [#27])

## 라디얼 2단 (훈련소 양성) [#26]
- 정착지 길게 끌기 → 방향=병종, 거리=속도.
- **안쪽 링=기본 병종 / 바깥 링=고급 병종·💰발행**. 멀수록 빠르고 고급.

## 상징 / 깃발
- **예슈아 진영(예슈아한민족국·진리단일국가)**: **예슈아하마쉬앟 성표**(8각 광채 별) 커스텀 아이콘 [#37][#38]. (초기 "예슈아한민족" 텍스트 상징 [#28] → 성표 아이콘으로.)
- **그 외 세력 깃발**: 세력명 **앞 세 글자** [#41][#42].
- **거짓 교단**(적대): ✝ 십자가 유지.

## 국경선 표시 [#39][#40]
- 지도식 실선(밝은 케이싱+어두운 선) + 세력색 면. 메인맵·미니맵.

## 게임엔진 · 데이터 편집기 [#92]
시작화면 **⚙️ 게임엔진** 버튼. 이 게임의 모든 데이터·수치를 인게임에서 편집·저장한다.
- **세력**: 이름·영웅·색 편집, **적대세력 추가/삭제**(추가 적대세력은 실제로 맵에 거점·부대로 등장). 플레이 7·궐기 7번은 구조상 고정.
- **병종**: 이름·아이콘·장비비 편집, **병종 추가/삭제**.
- **시작·경제 수치**: 세력/충성/무소속/적대 시작 병력, 시작 금화, 농지 수익, 병영 인력, 예슈아화 발행 비용·발행량, 점령 시간, 성 개수.
- **전투 상수**: 공격력 배율(10배당 ×4.2), 공격발동(+42%), 방어발동(−77%), 피해율, 포위 가중, 궁병 사거리, 해군 보너스, 함선 전투력, 예슈아대 회복.
- **저장/이식**: localStorage 자동 저장 + **JSON 내보내기/불러오기**(파일로 백업·공유), 기본값 복원.
