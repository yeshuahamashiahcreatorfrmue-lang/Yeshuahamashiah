# 00. 전체 설계 연혁 (처음 → 끝, 빠짐없이)

프로젝트 시작부터 현재까지 정해진 **모든 설계 결정**을 시간순으로 기록한다. 어떤 아이디어도 임의로 폐기하지 않으며, 지시하신 변경 이력만 그대로 보존한다. (※ 최종 사양은 01~13 문서 참조)

## 1. 기반
1. 7세력 모바일 웹 RTS+RPG 프로토타입(캔버스, 단일 파일).
2. **월드맵 RTS+RPG**로 재설계: 21군주 = 7세력 + 충성 개인 7 + 무소속 7. 지형 존, 카메라.
3. 월드맵 정비: 부드러운 바이옴, **데코(장식물)**, **이름 붙은 지역(named regions)**, 전술 지형, 미니맵, 저사양 최적화.

## 2. 경제·해상·무역 (초기 골격)
4. 경제·해군: **성을 가진 자만 병력 생산(세력)** / 성 잃으면 개인(궐기·몰락), 마을 병영·농지 강화, **항구=도하**, 조선소, 규모 등급별 군집 + 깃발.
5. 해상·무역 레이어: 함선 3종(**수송선/전함/유람선**), 항구 승선모드, **해군 전함 +42%**, 육↔해 전투, **바다·육상 무역 루프**, **기마병참원/기마무역소**, 함대, 재출항.
6. **영주(영웅) RPG**: 탭 이동 + 자동 교전, 내 부대 탭 선택으로 RTS 지휘(육군+함대).
7. 정착지 등급(촌락→도시), **성곽 포인트**(도시 기본1, 최대7), 정착지별 영역(소유색 국경/깃발, 점령 시 갱신 캐시).

## 3. 전투·병종 (상성 변천 포함)
8. 신 전투식: 공격력=`(troops/42)^0.623`(10배당 ×4.2), 피해=공−방(42블록), **상성(공격+42%/방어−77%)**, 포위, 원거리(궁병). 병종: 보병/기병/궁병.
9. 중규모/대규모 도시(기본 성곽 2/3); **궁병=원거리 전담**(별도 포격 채널, 상성 제외); 상성=보병▶기병으로 한정; 기병 이동속도 보너스.
10. **소총병 추가**: 상성 순환 보병▶소총병▶기병▶보병(기병이 보병, 소총병이 기병 제압); 궁병 원거리 유지.
11. **기갑(탱크) 추가**; 상성 순환 **기갑▶소총병▶기병▶기갑**으로 개편; 보병=저렴·상성 없음. 기갑 +25%·느림·포격피해 절반.
12. **훈련소 경제**: 보병(인력)→병종 전환 **라디얼 누르고-드래그**(펄스 420, 인력+세력자원 소모); 수도성 **금화(예슈아화) 발행**(드래그→💰, 펄스42, 금화 소모); 수도성 지정(대도시+궐기); AI는 보병만; 가게/개인 금화 유통; HUD 금화·수도 왕관·오버레이.

## 4. 전술 존 전투맵
13. **전술 존 전투맵(§K)**: 플레이어 관여 교전 시 진입. 병력을 420단위 **군집(밀물)**으로 전개해 적/군주로 밀려듦. 군주 직접 지휘(탭 이동), 아군 군집 통과·적 군집은 차단+피해, 결과를 월드 부대에 반영, 후퇴 버튼, 전투 후 쿨다운. AI끼리는 월드 추상 전투.
14. **존 심화**: 지형 반영(배경/엄폐 피해/속도), **해안 상륙 존**(바다 띠·해안선·상륙함선·도하 페널티), 전술 규칙 — 기병=기갑外 보너스, 궁병/소총병 7초 일제사격+카이팅, 보병 포위 −77%/정지 −42%(비기병), 포위 +42%. 군주 자동 진격, 80초 교착 방지, 병종색 블록.

## 5. 병종 대확장
15. 병종 15종: **포병/자주포병**(공성 원거리, 기갑 +42%), **예슈아대**(비전투 회복, 근처 아군 회복), **7세력 특수병종**(올라운더, 세력 영웅이 사용). **소총병=근접 재설계**(기병 카운터 ×2.02, 기갑外 공·방 +42%). 상성 tacAtk/tacDefMul 중앙화, 병종별 사거리, 라디얼에 8공통+자세력특수+💰.

## 6. 개인 마켓·라디얼 2단
16. **개인 예슈아화 마켓**: 🛒 상점(정착지 근처), 아이템(명검+15%공격, 흉갑−12%피해, 준마+18%속도, 군량+1800, 예슈아 성물 +12회복 → 이후 '야전병원'으로 명칭 변경 지시). 개인 지갑(처치 노획+지도자 봉록)에서 지불→그 세력 자산. **라디얼 2단**(안쪽 기본·바깥 고급/💰, 거리=속도).

## 7. 종교 정화·세력/영웅 개편
17. **천주교(성물/십자가) 색채 제거**: 예슈아 성물→야전병원, 예슈아대 ✝️→⛑️. **빛의 군단→예슈아한민족국**, 성광기사→예슈아한민족대.
18. **예슈아한민족 텍스트 엠블럼** + 8번째 빌런 세력 **거짓 교단**(천주교=거짓선지자, 특수 거짓사제, ✝ 십자가). NF=8.
19. 영웅 **세라핌→예슈아**; 거짓 교단 영웅 위선자→**거짓선지자**(타락한 악마 섬기는 거짓 선지자), 세력별 설명문.
20. 9번째 세력 **예슈아한민족진리단일국가** 삽입(index7, 영웅 예슈아하마쉬앟아버지랍비멜렉우앟엘로힘, 특수 예슈아행하기위해죽지않음지옥 ☀️), **거짓 교단 index8로 이동**.
21. **거짓 교단을 플레이 세력에서 제외 → 적대세력(HOSTILE) 목록**으로 분리(미배치). NF=8.
22. **7번=궐기 세력**: 시작 선택·배치 없음. **모든 개인이 궐기(첫 성 점령) 시 7번(예슈아한민족진리단일국가)으로 편입**(riseIntoTruth).

## 9. 상징·지도(맵) 표시
25. **예슈아하마쉬앟 성표**(8각 광채 별) 커스텀 아이콘 제작 → 예슈아 진영(0·7) 상징(시작화면 SVG·깃발·정착지). 빌런 십자가는 유지.

### 변경 지시 이력 (지시하신 순서대로, 폐기 아님)
> 아래는 사용자가 직접 "바꿔라"고 지시한 항목의 전·후 기록일 뿐, 어떤 것도 임의 폐기하지 않음. 필요 시 이전 안도 되살릴 수 있음.
