# 01. 개요 · 플레이어 구성 · 조작

## 장르
- 모바일 세로형 **월드맵 RTS + 개인 RPG** 하이브리드. 부대(간소화된 군대)와 개인이 한 월드맵 위를 돌아다닌다. [#4]

## 플레이어 구성 — 총 21 군주 [#5][#6]
- **세력 플레이어 7**: 각 세력의 영주(영웅).
- **세력 소속 충성 개인 7**: 세력에 속한 개인 군주(세력당 1).
- **무소속 7**: 어디에도 속하지 않은 독립 군주. 세력에 자동으로 붙지 않고, 열세/강세를 스스로 택해 독립적으로 플레이한다. (초기 "무소속이 세력을 자유로이 바꾼다"[#5]는 **#6에서 독립 유지로 정정**.)

## 세력 ↔ 개인 (궐기 / 몰락) [#8]
- **궐기 = 성/땅 소유**: 성을 가지면 '세력'이 되어 **병력을 생산**할 수 있다.
- **몰락 = 성 전부 상실**: 다시 떠도는 '개인'이 되어 생산 불가.
- 이 원리는 세력·충성 개인·무소속 **모두 동일**. 병력 생산의 유일 요건은 "궐기(성 소유) 여부".

## 조작 모드 [#13]
| 주체 | 성 보유 전 | 성 보유 후(궐기) |
|---|---|---|
| 세력 플레이어 | — (시작부터 영주+성) | **영주 캐릭(RPG) + RTS** |
| 충성 개인 | RPG | 성 하사 시 **RTS** 추가 |
| 무소속 | RPG (궐기 누르기 전) | 궐기 후 **RPG + RTS** |

- **영주(영웅)는 개인 플레이어 같은 존재** — 직접 조종(탭 이동 + 자동 교전)의 RPG 축. 성을 가지면 부대를 지휘하는 RTS 축이 더해진다.
- 모바일 전용: 세로 화면, 탭/드래그/핀치. [#14]

## 구현 현황
