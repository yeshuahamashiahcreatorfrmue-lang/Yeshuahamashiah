# 06. 전투 · 전술

## 기본 산식 [#16]
부대가 접촉하면 **공격력·방어력·전술발동·포위·원거리**를 따져 자동 실시간으로 병력을 차감한다.

- **공격력 척도**: 병력 **42명 = 1**, 병력 **10배마다 공격력 ×4.2**. (즉 공격력 = (병력/42)^log₁₀4.2)
- **차감 병력수 = 공격력 − 방어력.**

## 전술발동 (상성) [#16]
- 상성 우위일 때 발동. 두 종류:
  - **공격발동**: 상대 차감 병력수 **+42%**.
  - **방어발동**: 받는 차감 병력수 **−77%**.

## 상성 관계 [#18][#19]
- **기병 ▶ 보병**(보병이 기병에 박살).
- **소총병 ▶ 기병**(소총병이 기병에 강함).
- **보병**은 소총병에 강한 게 아니라 **그냥 저렴**.
- **기갑(전차)** 추가 — 중장갑, 느림, 원거리 포격 피해 절감.
- (세력 특수병종은 약점 없는 올라운더 보정.)

## 포위 [#16]
- 동시에 여러 부대에 교전당하면(포위) 받는 차감 가중.

## 원거리 포격 (궁병·포병류) [#17]
- **궁병은 상성이 아니라 원거리 포격 전담.** 근접 상성과 **별도 채널**로 병력 차감(원거리 포격 차감식).
- 기갑은 포격 피해 절감 [#19].

## 개인 관여 교전 → 전술 존 [#16]
- 개인(영주)이 관여하면 별도 전술맵. 420단위 군집이 물밀듯 밀려듦. 같은 세력 개인은 통과, 아니면 차단+피해(피해=420단위 공격력). → [08_전술존.md](08_전술존.md)

## 구현 현황
- 공격력 (42=1, ×4.2/10배)·차감=공−방 ✅
- 전술 공격발동 +42% / 방어발동 −77% ✅
- 상성(기갑▶소총병▶기병▶기갑 + 기병/소총병 특수규칙) ✅
- 포위 가중·궁병 원거리 별도 포격·기갑 포격 절감 ✅
