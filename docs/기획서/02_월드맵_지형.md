# 02. 월드맵 · 지형

## 지형 7종 [#6]
사막 · 산맥 · 초원 · 평지 · 진흙 · 강 · 바다.
- 강·바다 = 물(배 없이 못 건넘 [#8]). 나머지 = 육지.
- 지형은 **이동속도**와 **전투 엄폐(피해 보정)**에 영향(전술 깊이).

## 맵 구성 [#6][#7]
- 많은 성과 국경으로 채워진 대륙. 군대·개인이 충분히 뛰놀 크기.
- **최적화 필수**: 이미지(분위기)는 멋지게 하되 성능을 위해 존(zone) 단위로 잡아 처리.
- 작업 우선순위: **맵부터** 제작 [#7].

## 국경선 · 세력색 [#39][#40]
- 월드맵에 **세력색**(영토 면)과 **국경선**을 표시.
- 국경선은 블록/번짐이 아니라 **지도처럼 또렷한 실선**.
- 메인맵 + **미니맵** 모두 표시.

## 미니맵
- 우하단. 지형 + 세력색 + 국경 실선 + 성/유닛 점 + 시야 사각형. 탭/드래그로 시점 이동.

## 구현 현황
- 7지형 절차 생성·이동/엄폐 반영 ✅
- 국경선 지도식 실선 + 세력색(메인맵·미니맵) ✅
- 이름 붙은 지역·장식물·저사양 최적화 ✅
