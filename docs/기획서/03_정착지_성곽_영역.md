# 03. 정착지 · 성곽 · 영역/국경

## 정착지 등급 [#15][#17]
촌락 · 마을 · 중규모 마을 · 대규모 마을 · 도시 · **중규모 도시 · 대규모 도시**.
- 규모가 클수록 영역·시설·기본 병력 규모가 큼.

## 성곽 포인트 [#15]
- **성이 얼마나 잘 축성되어 있는지**를 나타내는 수치. **최대 7**.
- **도시는 기본 성곽포인트 1**(이상 등급은 더 높게).
- 성곽이 높을수록 방어 유리·**점령 지연**.

## 영역 · 국경 · 깃발 [#15]
- **촌락부터 모든 중심지**에 영역을 부여하고 국경을 설정.
- 점령 시 해당 영역/국경이 **점령 세력 소속**이 되고 **깃발**을 건다.
- 영역은 최근접 정착지 기준(보로노이). 국경 실선은 [02](02_월드맵_지형.md)·[11](11_개인RPG_마켓_상징_UI.md).

## 시설 (마을 업그레이드) [#8]
- **병영**: 병력 생산량↑(인력 충원·양성 펄스).
- **농지**: 수익(금화)↑.
- (해상/무역 시설은 [09](09_해상_해군_함선.md)·[10](10_경제_무역.md): 항구·조선소·기마무역소·유람선 정원.)
