# 00. 전체 결정 연혁 (채팅 원문 시간순)

원문 71개에서 게임 설계에 해당하는 지시를 시간순으로 정리. 어떤 아이디어도 임의 폐기하지 않으며, 사용자가 "바꿔라"고 한 변경만 전·후로 기록한다.

1. 한국어로 진행 [#2]. README 삭제 [#3].
2. **7세력·7개인 모바일 웹 RTS RPG**, 부대가 필드를 돌아다님(간소화된 군대) [#4].
3. 구성 확정: **세력 플레이어 7 + 세력 소속 충성 개인 7 + 무소속 7**. 무소속은 붙지 않고 독립적으로 플레이 [#5][#6].
4. 월드맵: 많은 성과 국경, **사막·산맥·초원·평지·진흙·강·바다**. 최적화하되 이미지 멋지게, 군대·개인이 뛰놀 만한 크기로 존을 잡음 [#6]. **맵부터** 작업 [#7][#14].
5. **물은 배 없이 못 건넘**, 항구 건설→승선, 세력은 전함 제조 가능. **세력=병력 생산**, 무소속도 궐기(성/땅 소유)하면 세력, 성 잃으면 다시 개인. 충성 개인·세력도 동일 원리. 병영·농지 업글로 수익·병력 강화. 병력은 개개인이 아니라 **42/420/4200/42000/420000/4200000 단위 군집**으로 크기·색·형태·병종·세력깃발로 간소화 표시 [#8].
6. 규모별 외곽 링 없이 **크기+명확한 수치**만. 전함=바다의 유일 전투선(별도 유닛). **수송선·전투선·유람선**(상업+개인 도하) [#9].
7. **육군↔해군 교전 가능**(강/바다와 육지가 한 맵일 때) [#10].
8. **해전 전용 해군 가득 찬 전함=공격속도·이동속도 +42%**. 함대전에서 탑승자가 해군이 아니면 **함선 성능만 적용, 탑승자 능력치 무효** [#12][#50].
9. 조작: 세력 플레이어=영주 캐릭(영주=개인 같은 존재) RTS. 충성 개인=성 하사 시 RTS, 그전 RPG. 무소속=성 점령·궐기 전까지 RPG, 이후 RPG+RTS [#13].
10. 정착지 등급 **촌락·마을·중규모마을·대규모마을·도시**. 도시 기본 성곽포인트 1, **성곽포인트=축성도, 최대 7**. 촌락부터 모든 중심지에 영역·국경, 점령 시 국경 소속·깃발 [#15]. 이후 **중규모/대규모 도시** 추가 [#17].
11. 전투: 부대 접촉 시 **공격력·방어력·전술발동·포위·원거리** 자동 실시간 교전으로 병력 차감. **병력 42=1, 10배당 ×4.2**. **차감=공격력−방어력**. 전술발동=상성 우위 시; **방어발동 −77%**, **공격발동 +42%**. 개인 관여 시 420단위 군집이 물밀듯 밀려듦, 같은 세력 개인은 통과·아니면 차단+피해(피해=420단위 공격력) [#16].
12. **궁병=상성 아님, 원거리 포격 전담**(별도 차감 계산식) [#17].
13. 상성: **보병은 기병한테 박살**, **소총병이 기병에 강함** [#18]. 보병은 소총병에 강한 게 아니라 **그냥 저렴**. **기갑(전차) 추가** [#19].
14. **훈련소**: 보병이 들어가 장비·훈련 받으면 **다른 병종 유닛 수가 생산**되어 증가 [#20].
15. **존맵 깊이화** [#23].
16. 병종 추가: **기병·궁병·포병·자주포병·보병·기갑·예슈아대(근처 병력 회복)**. + **7세력별 특수병종 1종씩**(팔방미인, 하나만 찍어도 쓸만한 독특 유닛) [#25].
17. AI는 마지막. **개인 예슈아화 마켓·아이템·라디얼 2단화** [#26].
18. **성물 등 천주교색 제거**. 빛의 군단→**예슈아한민족국**, 특수병종→**예슈아한민족대** [#27]. 십자가 대신 **"예슈아한민족" 텍스트 상징** [#28].
19. 영웅 이름 세라핌→**예슈아**. 천주교=**타락한 악마·거짓 선지자 세력**으로 묘사(거짓말) [#29].
20. 거짓교단을 7→8번으로, 7번에 **예슈아한민족진리단일국가**(특수 **예슈아행하기위해죽지않음지옥**, 영웅 **예슈아하마쉬앟아버지랍비멜렉우앟엘로힘**) [#30]. 이후 **거짓교단은 세력에서 빼 적대세력 목록**으로 [#31].
21. **7번 세력=궐기 시 택하는 세력** [#32]. 플레이어는 **거짓세력에 못 들어감** [#34]. **프로토타입 시연** [#34].
22. 대지 숭배 등 맥락 제거, 이름 **순우리말+유목 차용** [#35] → 너무 유목스러우니 **순우리말·고대 한국어 느낌**으로 [#36].
23. 십자가 아이콘을 **예슈아하마쉬'앟'** 새 아이콘으로 교체, 프로토타입 적용 [#37][#38].
24. 월드맵에 **국경선·세력색 표시** [#39] → 국경선을 **지도식 실선**으로 [#40].
25. **세력 깃발 아이콘=이름 앞 글자**(2→**3글자**) [#41][#42]. 내용 빠짐없이 **기획서에 전부**, **디렉토리로 분류 정리** [#41]. 구현 [#43].
26. 무역 등 **이전 자료 버리지 말고 전부 기록**, 말한 모든 것 빠짐없이 [#44][#48].
27. **유람선·기마병참원** 포함 [#45].
28. **기마무역소+기마대(기병류만) 묶기**, **기마병참대=기마병참원 수송량 +10%/100명, 상한 4200%** [#46].
29. 기획서는 코드 받아쓰기가 아니라 **사용자가 말한 설계로** 작성 [#47]. **임의 폐기 금지** [#49].
30. 유람선: 항구 2곳 왕복 수익(타 항구 도착=부유, **자기 세력 항구 도착 시 세력이 수익**). 육상 **무역로**: 기마무역소마다 말 달려 타 지역 생산물 **약탈/거래**→자기 무역소 도착 시 수익. 항구와 차이: 무역로는 **약탈물 수송도 하므로 전쟁지역에도 설치 쉬움**. 무역로 따라 **병참(곡물·장비·무기)·약탈물**을 옮기는 유람선 같은 유닛=**기마병참원** [#54].
31. **채팅 원문 영구 보존** 규칙·자동화(스크립트+훅+CLAUDE.md), /clear·리셋·새 인스턴스 불문 [#70].

## 사용자 변경 지시 이력 (폐기 아님 · 이전 안도 살아있음)
- 무소속: (세력에 붙음) → **독립 유지** [#5→#6].
- 상성: (보병▶기병만) → 보병↔기병, **소총병▶기병**, 그냥 보병 저렴 + **기갑 추가** [#16→#18→#19].
- 거짓교단: 8번 세력 → **적대세력 목록 분리** [#30→#31].
- 이름: (천주교색/유목풍) → **순우리말·고대 한국어** [#27~#36].
- 상징: "예슈아한민족" 텍스트 → **예슈아하마쉬앟 성표 아이콘** [#28→#37].
- 국경선: (보간 면) → **지도식 실선** [#39→#40].
- 깃발 글자수: 2 → **3** [#41→#42].
