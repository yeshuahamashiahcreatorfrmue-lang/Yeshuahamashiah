# 04. 전투 · 병종 상성

## 기본 산식 (월드 근접 `fight`)
```
raw = unitPower(공격) - unitPower(방어)×0.5      (최소 0.05)
raw ×= tacAtk(공.ttype, 방.ttype) × tacDefMul(방.ttype, 공.ttype)   // 병종 상성
raw ×= 1 + 0.2×min(3, 동시교전수-1)              // 포위(ENC)
raw ×= coverMul(방)                              // 지형 엄폐 × 성곽
raw ×= 0.85 (물 위 비-해군일 때)
raw ×= (방.gearDef||1)                           // 방어 장비
방.troops -= raw × 42 × 0.5(COMBAT_RATE) × dt
```
- `unitPower = atkBlocks(troops) × 병종계수 × (gearAtk||1)`
- `atkBlocks(t) = (max(1,t)/42)^log10(4.2)`

## 공격 상성 `tacAtk(공, 방)`
| 공격 병종 | 효과 |
|---|---|
| 기병(1) | 기갑(4) 제외 전부 ×1.42 |
| 소총병(3) | 기갑 ×1.0 / 기병엔 ×1.42×1.42=2.02 / 그 외 ×1.42 |
| 포병·자주포(5·6) | 기갑에 ×1.42(공성), 그외 ×1.0 |
| 세력 특수(≥8) | 전부 ×1.21 |
| 그 외(보병·궁병·기갑) | 순환 상성(`counters`) 성립 시 ×1.42 |

## 방어 상성 `tacDefMul(방, 공)` — 받는 피해 배수(↓=단단)
| 방어 병종 | 효과 |
|---|---|
| 소총병(3) | 기갑 공격 ×1.0 / 그외 ×(1/1.42)=0.70 (방어 +42%) |
| 기갑(4) | 공성(포/자주포) ×1.42 / 그외 ×0.7 |
| 세력 특수(≥8) | ×0.85 |
| 그 외 | 순환 방어상성(`counters`) 성립 시 ×0.23(TAC_DEF) |

## 순환 상성 `TBEAT = {4:3, 3:1, 1:4}`
기갑 ▶ 소총병 ▶ 기병 ▶ 기갑. (보병·궁병은 순환 밖. 기병/소총병은 위 특수 규칙으로 재정의됨)

## 원거리 포격 `rangedHit` (궁병·포병·자주포)
```
raw = atkBlocks(troops) × (공성이면 1.1, 아니면 RANGED_K=0.7)
raw ×= coverMul(방)
기갑 대상: 공성이면 ×1.42(특효), 궁병이면 ×0.5(약함)
raw ×= (방.gearDef||1)
방.troops -= raw × 42 × 0.5 × dt
```
사거리 내 적에게 매 프레임 별도 채널로 차감(근접과 무관).

## 예슈아대 회복 (비전투 지원)
- 같은 팀 부대가 사거리 74 안에 있으면 초당 46씩 병력 회복(상한 capMax).

## 지형 엄폐 `coverMul`
- `TERR[지형].def` 배수(<1=엄폐로 피해↓, >1=노출로 피해↑) × 성곽 보너스(`1-fort×0.08`, 하한 0.4).

## 장비 보정(개인 RPG) — [07 참고](07_마켓_아이템.md)
- `gearAtk`(공격 ×), `gearDef`(받는 피해 ×, ↓), `gearSpd`(이동 ×), `gearRegen`(초당 회복). 군주(개인)에게 적용.
