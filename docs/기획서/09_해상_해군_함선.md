# 09. 해상 · 해군 · 함선

## 도하 [#8]
- **물은 배 없이 못 건넌다.** **항구**를 건설하면 승선 가능. 세력은 전함을 제조할 수 있다.

## 함선 종류 [#9]
- **전함(전투선)**: 바다 맵에서 **유일하게 돌아다니는 전투선**(별도 유닛).
- **수송선**: 육군 도하용.
- **유람선**: 상업(무역) + 개인 플레이어가 몰래 타고 넘어가는(도하) 용도.

## 육군 ↔ 해군 전투 [#10]
- 강/바다와 육지가 한 맵에 있을 때 육군과 해군이 서로 싸울 수 있다.

## 해군 전함 보너스 [#12][#50]
- **해전 전용, 해군으로 가득 찬 전함**: **공격속도 +42% · 이동속도 +42%.**
- **함대전에서 탑승자가 해군이 아닌 경우**: **함선 성능에만 영향**, **탑승자(육군 등) 능력치 무효.**

## 구현 현황 (실제 코드 기준)
- 도하(항구 승선)·전함/수송선/유람선·육↔해 전투 ✅
- 해군 전함 +42%: 전투력(unitPower ×NAVY_BONUS) ✅ / 이동속도(moveUnit ×NAVY_BONUS) ✅
- **비해군 전함**은 함선 성능 고정(atkBlocks 2000, 탑승자 무효) ✅
- **비해군 수송선**은 아직 탑승 병력(troops) 기반 → "탑승자 능력치 무효"(#50) **미반영 ⏳**
- "공격속도 +42%"는 별도 쿨다운 아니라 연속전투 **피해율**로 반영 🟡
