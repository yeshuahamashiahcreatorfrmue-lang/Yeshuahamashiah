# 13. 성장(RPG) · 영웅 조작 · 함대 지휘

## 영웅 군주 = 플레이어 아바타 (RPG)
- 플레이어는 선택 세력의 **영웅 군주**를 직접 조종(탭 이동, 적 탭 공격, 근처 적 자동 교전).
- 군주가 관여한 교전은 [전술 존](05_전술존.md)으로 들어가 직접 지휘.
- 군주 병력 0 = 패배(게임오버, 생존 시간 표기).

## 레벨 · 경험치
- 유닛마다 `lvl/xp/xpNeed/atk`. 적 처치 시 경험치 획득.
- 레벨업: `xpNeed ×1.5`로 증가, `atk += 6`. HUD에 레벨·경험치 막대 표시.
- 실질 전투 강화 지렛대는 **병력수(troops)와 장비(gear)**([04](04_전투_전술.md)·[07](07_마켓_아이템.md)). atk는 성장 표시값.

## 처치 노획 · 봉록
- 적 처치 시 예슈아화 `coin += min(80, 적병력×0.02)`.
- 지도자 봉록: 보유 성 수에 비례한 예슈아화 적립([06](06_경제.md)).

## 장비(개인 마켓)
- 정착지 상점에서 명검/흉갑/준마/군량/야전병원 구매 → `gearAtk/gearDef/gearSpd/gearRegen` 강화([07](07_마켓_아이템.md)).

## 세력 ↔ 개인 ↔ 궐기
- 성 보유=세력(양성 가능), 모두 잃으면 개인(떠돌이). 개인이 첫 성 점령=궐기 → 예슈아한민족진리단일국가 편입([08](08_정착지_점령_궐기.md)).

## 함대/부대 지휘 (RTS)
- 영웅 탭 = 선택 해제(영웅 직접 조종).
- 다른 아군 부대/함선 탭 → 인접(160) 묶음 선택(`selFleet`).
  - 빈 곳 탭 = 대형 이동(오프셋 배치), 적 탭 = 교전, 유람선 = 경로 수정(`manualTarget`).
  - 기마병참원(육상 교역)은 자동 무역 전용 → 직접 선택 제외.
- 도하: 육군이 물에 들어갈 때 항구 승선모드(수송선/전함) 또는 유람선 ferry 사용([11](11_무역_해상.md)).

## 카메라/미니맵 조작
- 핀치 줌, 드래그 패닝, 미니맵 탭/드래그로 시점 이동(`mmJump`).

## 정착지 운영(마을 패널)
- 자기 성 탭 → 패널: 성곽 축성 · 병영/농지 강화 · 항구/조선소/기마무역소 건설 · 승선모드 전환 · 유람선 증선.
- 길게 눌러 드래그 = [2단 훈련 라디얼](09_맵_UI.md)(양성/발행).
