# 몹 탭 (캐릭터식 모션·이펙트·이미지) + 탄생 타이밍

사용자 선택: **완전 별도 몹 탭 신설** + 캐릭터처럼 모션/이펙트/이미지 편집.

## 구현
- [x] **새 "몹" 탭** (툴바: 캐릭터 옆). 캐릭터 빌더를 그대로 재사용한다.
  - 데이터 모델: 몹 = `CharacterDef` (별도 리스트 `Database::mobs`). 캐릭터의
    모션(6종×4방향)·이펙트·이미지 시스템을 100% 동일하게 사용.
  - 빌더 공유: `mobMode_` 플래그로 `db.characters↔db.mobs`, `charDefSel_↔mobSel_`를
    전환 — 한 벌의 에디터가 두 탭을 구동(중복 코드 없음).
  - `src/database/Database.{h,cpp}`(mobs 리스트+직렬화 헬퍼 charToJson/charFromJson),
    `src/editor/Editor.{h,cpp}`(Tab::Mob, 디스패치), `src/editor/EditorChars.cpp`(list/sel 라우팅)
- [x] **몹 전용 데이터**: 데이터 수정 창에 처치 경험치·골드·드롭 아이템/확률,
  **탄생 정지(ms)**, **탄생 주기(초)** 추가.
  - CharacterDef에 expReward/goldReward/dropItemId/dropRate/spawnFreezeSecs/respawnSecs
- [x] **이미지 등록 = 윈도우 탐색기**: 몹 탭의 이미지 소스 패널에
  "+ 내 이미지 불러오기 (PNG·JPG·GIF…)"로 OS 탐색기에서 바로 등록(웹처럼).
- [x] **갑툭튀 방지(탄생 정지시간)**: 필드에 소환된 몹은 spawnFreeze 동안
  **무적 아님이지만 공격 불가 + 서서히 페이드인**되어 등장 직후 바로 때리지 않음.
  같은 이름의 몹 정의가 있으면 그 정지시간을, 없으면 기본 1.2초 적용.
  - `src/game/PlayTypes.h`(FieldMonster.spawnFreeze), `src/game/GamePlayMonsters.cpp`
    (소환 시 설정·매 프레임 감소·공격 차단·페이드인 렌더)
- [x] 한글 입력: 이전 라운드 textField 수정으로 몹/캐릭터 이름 모두 한글 입력 가능.

## 이번에 일부만 진행 / 다음 라운드
- 맵 위 **몹 등장지점 배치** + **미리보기 마커**: 몹 저작은 완성됐고, 맵에 스폰
  지점을 찍어 배치하는 UI와 미리보기 표시는 다음 단계.
- **탄생 주기(respawn) 런타임**: 값 저장은 되며, 처치 후 주기적 재생성 루프 연결은 다음 단계.
- **모든 탭 아코디언(펼침) 전면 개편**: 몹/캐릭터/이미지 패널은 이미 "목록+선택+
  탐색기 등록" 형태로 동작. 전 탭 일괄 아코디언화는 큰 작업이라 분리 진행.
- 마을 테두리 나무 삭제·엔터 채팅: 이번 우선순위 선택에서 제외됨(추후).
