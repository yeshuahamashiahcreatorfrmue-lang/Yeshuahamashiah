# 8종 이벤트 전수 제작 + 기능 부족 체크리스트 + 보강

모든 이벤트 종류를 7개씩(총 56개) `maps/93.json`("이벤트 시험장")에 제작하면서
각 종류의 부족한 기능을 찾아 체크리스트로 정리하고, 전부 구현했다.

## 제작 현황 (7개 × 8종 = 56)

| 종류 | 7개 변형 예시 |
|------|----------------|
| 메시지 | 기본/여러 줄/화자 이름/초상화/선택지/접촉발동/조건부 |
| 이동 | 대상맵·도착방향(유지/4방향) 변형 |
| 아이템지급 | 지급/다수지급/골드/회수(음수)/혼합/스위치/골드차감 |
| 스위치설정 | ON/OFF/변수대입/변수증가/동시/무문구/초기화 |
| 전투 | 필드 소환 3종 + 즉시 턴제 4종 |
| 상점 | 다품목(3·5·7)/단일/특화 상점 |
| 퀘스트 | 처치/수집/도달/즉시/아무거나/완료스위치 |
| 엔딩 | 게임 클리어 7개 |

## 기능 부족 체크리스트 → 전부 구현 완료

- [x] **메시지: 화자 이름표** (`speakerName`) — 대화창 위 이름 패널
- [x] **메시지: 초상화** (`faceAsset`) — 대화창 옆 인물 그림
- [x] **메시지: 선택지 분기** (`choiceA/choiceB/choiceSwitch`) — 예/아니오 등
      2지선다, 선택 결과를 스위치에 저장(A=ON/B=OFF)
- [x] **이동: 도착 방향 지정** (`faceDir`) — 도착 후 바라보는 방향
- [x] **아이템지급: 골드 지급/차감** (`giveGold`) + **회수**(`amount` 음수)
- [x] **스위치설정: 변수 대입/증가** (`varId/varOp/varValue`)
- [x] **전투: 즉시 턴제 전투** (`battleTurnBased`) — 기존 필드 소환에 더해
      이벤트로 턴제 전투 진입
- [x] **상점: 다품목 판매** (`shopItems[]`) — 여러 상품 목록 + 품목별 구입 버튼
- [x] **퀘스트: 완료 시 스위치 ON** (`rewardSwitch`) — 진행 게이트 연동
- [x] **공통: 변수 발동조건** (`conditionVar/conditionVarMin`) — 스위치 외에
      "변수 ≥ N" 조건으로도 이벤트 발동 제어 (상호작용/자동실행/접촉 모두 적용)

## 에디터(이벤트 패널)

- 종류별 라벨 그리드에서 선택 → 해당 종류 입력 필드만 표시(스크롤).
- 다중 텍스트 입력(대사/화자/선택A/선택B) 포커스 관리, 초상화 순환 선택.
- 대상(맵/적/아이템) ID 옆 실제 이름·없는 대상 빨간 경고.

## 검증

- 셀프테스트: 8종 신규 필드 직렬화 전수 통과(`testEventFields`) + 퀘스트 로직.
- 헤드리스 스크린샷: 다품목 상점, 선택지 대화(화자+버튼), 메시지 이벤트
  인스펙터(화자/초상화/선택지/발동조건) 확인.
- 56개 이벤트 시험장(map 93) 프로젝트 등록·로드 확인, 데이터-only 한글 글리프
  베이킹 처리.
