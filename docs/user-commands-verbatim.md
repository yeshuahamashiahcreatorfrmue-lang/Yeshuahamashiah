# 사용자 명령 원문 기록 (verbatim) 및 실현 현황

아래는 사용자가 내린 명령을 **있는 텍스트 그대로** 기록한 것이다. 각 항목을
이 기록에 따라 전부 실현한다.

---

## 원문 (직전 대규모 배치)

> 그리고 슬라임등 모든 몹들 설정에 탄생 정지시간. 탄생주기 설정해서(몸탭 만들기)
> 갑툭튀해서 바로 때리지 않게 설정할수 있게 만들고 모든 몬스터들이 나올때 등장
> 지점을 설정 힐수 있게 만들고 몹 탭을 만들고 몹 맵 위에 몹이 어느 지점에서
> 나오고 어떤 몹이 나오고 몹의 이미지도 등록할 수 있게 하고 몹의 이펙트 모션등도
> 전부 캐릭터 처럼 똑같이 만들 수 있도록 만들어라. 그리거 미리보기 창에도 몹
> 등장 위치 표시해주고.
>
> 지금 모든 패널들이 클릭했을때 다른 내용으로 전환되는데 그렇게 하지말고 모든
> 탭을 클릭했을때 어떤 선택지가 있는지 펼쳐짐 으로 전부 보고 그 중에서 선택
> 할수 있게 만들어라. 그리고 외부 추가의 경우는 윈도우 탐색기로 웹처럼
> 등록할수 있게해라
>
> 또 예슈아하마쉬앟 복종마을 테두리 나무들은 전부 삭제해라 이상하게 에셋으로
> 취급이안되고 타일 변경도 안된다.
>
> 엔터 누르고 말풍선 채팅 칠수 있게 만들거 오른쩍에 채탱 내용을 볼수 있는
> 창을 만들어라.

---

## 명령 분해 → 실현 현황

1. 모든 몹 설정에 **탄생 정지시간** + **탄생주기** (몹 탭 만들기), 갑툭튀 방지
   - 몹 탭/정지시간/갑툭튀 방지: 완료(이전). 탄생주기 런타임: 이번에 완료.
2. 모든 몬스터 **등장 지점**을 맵 위에 설정(어느 지점·어떤 몹), 몹 이미지 등록,
   몹 이펙트·모션을 캐릭터처럼: 저작 완료(이전). **맵 위 등장지점 배치: 이번에 완료.**
3. **미리보기 창에 몹 등장 위치 표시**: 이번에 완료.
4. 모든 탭을 클릭 시 전환 말고 **펼침으로 전부 보고 선택**, 외부 추가는 **윈도우
   탐색기**로: **완료.** DB 탭(유일하게 내용이 전환되던 탭)을 **아코디언**으로 개편
   — 아이템/액터/적 분류가 한 화면에 모두 펼쳐지고, 헤더로 접기/펴기, 항목 클릭으로
   선택·편집(뷰 전환 없음). 나머지 탭(월드/맵/NPC/이벤트/캐릭터/몹/에셋)은 이미
   목록+선택 구조. 외부 이미지 추가는 탐색기("+ 내 이미지 불러오기")로 동작.
5. **예슈아한민족진리복종마을 테두리 나무 전부 삭제** (에셋 취급/타일 변경 안 됨):
   완료(맵 JSON에서 304타일 제거 + 생성기 수정).
6. **엔터 말풍선 채팅** + **우측 채팅창**: 완료. 스킬바를 **하단 가로 스트립**으로 옮겨
   우측 열을 비우고, **채팅 로그창을 우측(미니맵 아래)에 배치**. 머리 위 말풍선 표시.
   **MMO 채팅 동기화 완료** — Net 프로토콜에 채팅(C/M) 추가, 호스트가 전원에게 중계,
   원격 플레이어 머리 위에도 말풍선 표시.
