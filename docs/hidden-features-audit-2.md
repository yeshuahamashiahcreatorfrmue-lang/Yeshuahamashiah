# 숨은 기능 점검 (2차) — 코드에는 있으나 화면에 안 나오던 기능

엔진의 모든 기능을 점검해, **코드/데이터에는 구현되어 있으나 화면에 표시·동작하지
않던 부분**만 따로 추려 화면에서 동작하도록 고쳤다. (1차에서는 턴제 전투/랜덤
인카운터를 화면에 연결했다.)

## 점검 결과: 실제로 화면에 안 나오던 항목 (수정 대상)

- [x] **인게임 ESC 메뉴 · 아이템 페이지가 구식 시스템 사용**
  - 증상: `Menu::drawItems`/`update`가 옛 `ItemEffect`(HealHP/HealMP)만 처리하고
    신규 식품 필드(포만/수분/healHp/healGp/보너스/버프)는 무시했다.
  - 수정: 공용 `GameState::consumeFood`/`equipItem`으로 일원화. 분류(식품/장비)
    태그와 선택 아이템의 효과 상세줄(포만+/수분+/HP+/GP+/공·방·속/버프 초)을 표시.
- [x] **인게임 ESC 메뉴 · 장비 페이지가 구식 무기/방어구 사용**
  - 증상: `m.weaponId`/`m.armorId` + `db.equipment`(Equipment) 기반이라, 실제
    플레이에서 쓰는 신체부위 장비(`GameState::equipped`, Item kind==2)와 단절.
  - 수정: 7개 신체 부위(머리/몸통/손/다리/발/무기/장신구) 슬롯으로 재작성.
    좌/우로 인벤토리의 해당 부위 장비 교체, Enter로 해제, 총 공/방/속 표시.
- [x] **인게임 ESC 메뉴 · 상태 페이지에 포만/수분 없음**
  - 수정: `drawStatus`에 포만/수분 수치 + 활성 버프 목록 추가, 실효 스탯 표기.
- [x] **식품 버프 지속시간(`Item.buffSecs`)이 데이터/에디터에만 있고 미사용**
  - 증상: DB 탭에서 "식품 버프 지속"을 편집·직렬화하지만 게임에서 효과 없음.
  - 수정: `buffSecs>0` 식품은 보너스를 **시간제 버프**(`GameState::buffs`)로 적용,
    매 초 카운트다운 후 자동 원복(`tickBuffs`). HUD 좌측 배지 + 상태창에 표시,
    세이브/로드 직렬화. 샘플에 `전투식량`(공+5, 60초) 추가.

## 점검 결과: 이미 화면에 정상 표시 중 (오인 방지용 확인 완료)

- [x] 스킬 바인딩(Z/X/C/V/F/G) → 필드 우측 스킬 패널(`drawSkillPanel`) 표시
- [x] 몹/NPC 전투 스탯 → 머리 위 HP 바(`GamePlayMonsters`/`GamePlayNpc`) 표시
- [x] 허기/목마름(포만/수분) → 필드 HUD 우상단 바 + 식품 회복 동작
- [x] 신체부위 장비/인벤토리 그리드 → I/C 키 + 하단 버튼으로 동작
- [x] 어둠/날씨/낮밤 → 플레이 렌더에서 실제 표시
- [x] 진행도 목표(objective) → HUD 상단 표시

## 검증

- 셀프테스트: 식품 섭취(클램프)·식품 버프 적용/만료/직렬화·장비 장착/해제/원복 통과.
- 헤드리스 스크린샷: ESC 메뉴 아이템/장비/상태 3페이지 + 버프 배지 표시 확인.
